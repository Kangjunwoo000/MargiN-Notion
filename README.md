# 마지노선 (MargiN-Notion)

> **"과제 마감에 대한 새로운 생각(Notion), 나만의 마지노선"**  
> 데드라인(Deadline)에 쫓기지 않고 나만의 시작 시점(Startline)을 찾아주는 과제 플래너

---

## 📌 프로젝트 소개
**마지노선(MargiN-Notion)**은 대학생들의 벼락치기 습관을 방지하고, 부담스러운 과제를 작은 단위로 나누어 자신만의 페이스로 완주할 수 있도록 돕는 인터랙티브 플래너입니다.

* **Margin (시간적 여유):** 마감 전 최소 5분~30분의 안전 마진(Buffer) 확보
* **Notion (새로운 발상):** 마감일이 아닌 '시작 시점'에 집중하는 새로운 시간 관리 방식

---

## ✨ 핵심 기능

1. **과제 시나리오 및 가용 시간 분석**
   - 단일/다중 과제 등록 및 공강/여유 시간대 자동 시각화
2. **맞춤형 페이스 추천**
   - 조금씩 나눠서(분산형) vs 제출일 가까이 몰아서(집중형)
   - 50분 집중 + 10분 휴식 리듬 자동 배치
3. **시작 마지노선 역산 & 주간 캘린더**
   - 제출 마감 및 휴식 시간을 역산하여 늦어도 언제 시작해야 하는지 마지노선 제공
4. **직접 조정 및 작업 분할(Split)**
   - 큰 과제를 2개 이상의 블록으로 손쉽게 분할하고 직접 일정 조정 가능
   - 연속 50분 초과, 가용 시간 이탈, 마감 초과 등 실시간 유효성 검증 및 코칭 제공

5. **조정 전후 비교**
   - 직접 조정 후 ‘이 일정으로 확인’을 누르면 추천 일정과 시작·완료·제출 여유를 과제별로 비교
   - 예: 전체 작업을 20분 늦추면 제출 여유가 30분에서 10분으로 감소
   - 미배치 작업이나 입력 누락은 계산 보류, 충돌 일정은 ‘수정 필요’로 구분
   - 다시 수정하면 이전 비교를 숨기고, 재확인해도 비교 기준은 추천 일정으로 유지

## 🛠️ 기술 스택
* **Framework:** Next.js (App Router, Turbopack)
* **Frontend:** React 19
* **Styling:** CSS3 (Responsive Design)

---

## 🚀 로컬 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속합니다.

## 검증

`npm test`로 시간 이동, 마감 초과, 미완성 입력, 작업 분할, 복수 과제 비교를 확인합니다. `npm run build`로 배포 빌드를 확인합니다.
